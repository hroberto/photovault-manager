## Convenções

- Use um único título de nível 1 por documento e níveis consecutivos para suas seções.
- Identifique a linguagem dos blocos: `bash`, `rust`, `json`, `sql` ou `text` para diagramas.
- Use links relativos para arquivos do projeto e links oficiais para regras das APIs.
- Diferencie comandos disponíveis, exemplos de projeto e recursos planejados.
- Registre a data de verificação quando documentar regras externas sujeitas a mudanças.
- Preserve os ADRs aceitos; mudanças de decisão devem gerar um novo registro.
